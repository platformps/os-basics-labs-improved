About this lab

The shell is the Linux command interpreter. It is also called the terminal, the command line, or the command prompt. In this lab you use the shell to read built-in help, move around the file system, send command output to files, and copy, move, and delete files and folders.

Objectives

  • Part 1: Shell basics
  • Part 2: Copying, deleting, and moving files

This simulation stands in for the Security Workstation virtual machine. You are logged in as analyst; the password is cyberops. Open Terminal from the Applications button to begin.

Part 1: Shell basics

Step 1: Access the command line

  1. Choose Applications on the dock and open Terminal.

Step 2: Display manual pages

The man command shows a command's manual page, which is the built-in documentation for that command and its options.

  1. Run man man to learn about manual pages.

Name a few sections that are included in a man page.

Name, Synopsis, Configuration, Description, Options, Exit status, Return value, Errors, Environment, Files, Versions, Conforming to, Notes, Bugs, Example, Authors, and See also.

On a real system, a man page opens in a pager: press q to quit it. Here the page is printed in full.

  1. Run man cp.

What does the cp command do?

It copies files and directories from one location to another.

What command would you use to learn more about the pwd command? What does pwd do?

man pwd. pwd prints the name of the current working directory, the folder you are in.

Step 3: Create and change directories

Directory is another word for folder. You will use cd (change directory), mkdir (make directory), and ls (list).

  1. Run pwd.

What is the current directory?

/home/analyst, the home directory of the analyst user.

  1. If you are not in /home/analyst, run cd /home/analyst.
  2. Run ls -l. The -l option shows details for each item: permissions, owner, size, the date it was last modified, and more.
  3. Create three folders: run mkdir cyops_folder1, then mkdir cyops_folder2, then mkdir cyops_folder3. Run ls -l to check.
  4. Run cd /home/analyst/cyops_folder3.

Which folder are you in now?

/home/analyst/cyops_folder3. The prompt shows cyops_folder3 as the current folder.

In the prompt [analyst@secOps ~]$, the tilde (~) stands for your home directory, /home/analyst. Changing folders changes where you are working, not where your home directory is. The dollar sign means a regular user; a number sign (#) means the root user. Prompts can be customized, so they look different on other systems.

  1. Challenge: run cd ~.

What happened, and why?

You returned to /home/analyst. The shell reads ~ as a shortcut for the current user's home directory.

  1. Run mkdir /home/analyst/cyops_folder3/cyops_folder4, then ls -l /home/analyst/cyops_folder3 to check.

So far you have used absolute paths, which start at the root directory (/). Relative paths start where you are and save typing. Every folder contains two special entries: . means this folder and .. means the folder above it, the parent.

  1. Run ls -la /home/analyst/cyops_folder3 to see the . and .. entries.
  2. Run cd /home/analyst/cyops_folder3, then cd .

What happens when you run cd . (dot)?

Nothing seems to happen: the shell changed to the current folder itself.

  1. Run cd ..

What happens when you run cd .. (two dots)?

You move up one level, to /home/analyst, the parent of cyops_folder3.

What would the current directory be after cd .. at each of these prompts: [analyst@secOps ~]$, then [analyst@secOps home]$, then [analyst@secOps /]$?

From ~ (/home/analyst) you go to /home. From /home you go to / (a forward slash), the root of the file system. From / you stay at /, because the root directory has no parent.

Step 4: Redirect output

The > operator sends a command's output to a file instead of the screen.

  1. Run cd /home/analyst.
  2. Run echo This is a message echoed to the terminal by echo. The message appears on screen.
  3. Run echo This is a message echoed to the terminal by echo. > some_text_file.txt

No output was shown. Is that expected? Explain.

Yes. The output went into the file some_text_file.txt instead of to the screen. The file did not exist before, so the shell created it.

  1. Run ls -l some_text_file.txt, then cat some_text_file.txt.
  2. Run echo This is a DIFFERENT message, once again echoed to the terminal by echo. > some_text_file.txt, then cat some_text_file.txt.

What happened to the text file? Explain.

The old text was replaced by the new message. The > operator empties the file before it writes.

Step 5: Redirect and append

  1. Run echo This is another line of text. It will be APPENDED to the output file. >> some_text_file.txt, then cat some_text_file.txt.

What happened to the text file this time? Explain.

The new line was added to the end and the earlier text stayed. The >> operator appends instead of replacing.

Step 6: Hidden files

Files and folders whose names start with a dot are hidden from a normal listing. Do not confuse them with the single dot that means the current folder.

  1. Run ls -l in your home folder, then ls -la.

How many more items does ls -la show than ls -l? Why?

Many more. ls -la also shows the hidden items, plus the . and .. entries. The exact number depends on what you have done in the workstation.

Can whole directories be hidden this way? Give three examples of hidden items from the ls -la output.

Yes, there are several hidden directories. Examples: .config, .cache, .bash_history, .bashrc, and .xinitrc.

  1. Run man ls and find the -a option.

Part 2: Copying, deleting, and moving files

Step 1: Copy files

cp copies a file. The first parameter is the source and the second is the destination. The original stays where it was.

  1. Run cp some_text_file.txt cyops_folder2/

What are the source and destination, written as full paths?

Source: /home/analyst/some_text_file.txt. Destination: /home/analyst/cyops_folder2/some_text_file.txt.

  1. Run ls cyops_folder2/, then ls -l to see that the file is in both places.

Step 2: Delete files and directories

  1. Run rm some_text_file.txt, then ls -l.
  2. Directories are a type of file too, but deleting one needs the -r (recursive) option, which also deletes everything inside it. Run rm -r cyops_folder1, then ls -l.

Step 3: Move files and directories

mv works like cp, but it removes the file from its original place. The . destination means "the folder I am in."

  1. Run mv cyops_folder2/some_text_file.txt ., then ls -l cyops_folder2/ and ls -l /home/analyst/.
  2. cyops_folder2 is now empty. Delete it and anything that might be inside it with one command.

What command did you use to delete cyops_folder2?

rm -r cyops_folder2. Because the folder is empty, rmdir cyops_folder2 also works.

Reflection

What are the advantages of using the Linux command line?

Answers vary. The command line gives more options and control than graphical tools, commands can be combined into scripts to automate routine work, and it uses few resources, which matters when managing computers remotely.
