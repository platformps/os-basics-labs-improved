About this lab

Task Manager shows what is running on a Windows computer and how much of the computer's resources each item uses. You can also use it to end a program that has stopped responding. In this lab you work with the Processes, Services, and Performance pages.

Objectives

  • Part 1: Work in the Processes tab
  • Part 2: Work in the Services tab
  • Part 3: Work in the Performance tab

Graphs as text: The real Performance tab draws live graphs. This simulation gives you the same readings as text, which is also how a screen reader user reads them in real Task Manager.

Part 1: Work in the Processes tab

  1. Open Command Prompt and Microsoft Edge from Start. Any web browser would work in real life; this lab uses Microsoft Edge. For extra practice, open Microsoft Edge twice.
  2. Open Task Manager: choose Taskbar options on the simulated taskbar, then Task Manager. On a real PC you can also press Ctrl+Shift+Esc, or press Ctrl+Alt+Delete and choose Task Manager.
  3. If Task Manager shows only a short list of apps, choose More details.
  4. The Processes tab has three tables: Apps, Background processes, and Windows processes. In the Apps table, expand Windows Command Processor with the Expand button before its name.

What is listed under Windows Command Processor?

Command Prompt, which is the window that cmd.exe is running in.

  • Apps are programs you opened, such as Microsoft Edge, Task Manager, and Windows Command Processor.
  • Background processes run in the background, such as OneDrive or the antivirus engine. Some are started by apps you have open.
  • Windows processes are core parts of Windows, including the processes that host Windows services.
  1. Opening a command window also starts Console Window Host, which is listed in the Windows processes table. Select it, open its Actions, and choose Properties.

What is the file name and location of the Console Window Host process?

The file is conhost.exe, and it is in the C:\Windows\System32 folder.

  1. Close the Command Prompt window, then switch back to Task Manager.

What happened to Windows Command Processor and Console Window Host when you closed the Command Prompt window?

Both processes ended, so they are no longer listed in Task Manager.

  1. Choose the Memory column header to sort. Choose it a second time.

What effect does sorting by Memory have on the tables?

Each table is sorted by how much memory each process uses. The first sort puts the largest first; choosing the header again reverses the order, smallest first.

  1. Move to the Memory column header and press Shift+F10 (or right-click it). Choose Resource values, then Memory, then Percents.

What effect does this have on the Memory column?

The Memory column shows each process's memory use as a percentage of the computer's total memory instead of in megabytes.

How could showing memory as percentages be useful?

It shows at a glance which processes use a large share of the available memory, which helps an administrator find the cause of memory problems or slowdowns.

  1. Select Microsoft Edge in the Apps table, open its Actions, and choose Switch to. (In the original lab you double-click it; in current Task Manager, double-clicking expands the group instead.)

What happens when you choose Switch to?

The Microsoft Edge window becomes the active window.

  1. Return to Task Manager, select Microsoft Edge, and choose End task.

What happens to the web browser windows?

All Microsoft Edge windows close, because End task on the group ends every Edge process.

Part 2: Work in the Services tab

  1. In Task Manager, go to the Services tab and review the list.

Which statuses are listed?

Running and Stopped.

Part 3: Work in the Performance tab

  1. Go to the Performance tab. The CPU page is shown first.

How many threads are running?

Answers vary on a real PC. This simulation shows 1,271.

How many processes are running?

Answers vary, and the number changes as you open and close apps. In this simulation it is about 100.

  1. Choose Memory in the list of resources.

What is the total physical memory, in MB?

4.0 GB, which is 4,096 MB (1 GB is 1,024 MB). Answers vary on a real PC.

What is the available physical memory, in MB?

2.5 GB, which is about 2,560 MB.

How much physical memory is in use, in MB?

1.4 GB, which is about 1,434 MB.

  1. Choose Ethernet in the list of resources.

What is the link speed?

1.0 Gbps in this simulation. Answers vary on a real PC.

What is the IPv4 address of the PC?

192.168.1.15 in this simulation.

  1. Choose Open Resource Monitor to open Resource Monitor from the Performance tab. Explore its tabs.

Reflection

Why is it important for an administrator to know how to work in Task Manager?

Task Manager is a quick troubleshooting tool. It shows CPU, memory, disk, and network use, shows which processes and services are running, and lets you end a process that has stopped responding or that looks suspicious.

Corrections from the original lab

  • The original sample answer for link speed says "it is a Ethernet Connection." The link speed is a rate such as 1.0 Gbps.
  • The original asks for memory in MB but gives answers in GB. Both units are given here.
  • The original says Windows processes are Windows services. That group holds core Windows processes, including the processes that host services.
  • Double-clicking an app in current Task Manager expands it instead of switching to it. This version uses Switch to.
