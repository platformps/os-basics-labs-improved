About this lab

Every person who uses a Windows computer should have their own account. In this lab you create a standard local account, see how Windows keeps each account's files private, look at the account in Local Users and Groups, make it an administrator and then take that away, and finally delete it.

Objectives

  • Part 1: Create a new local user account
  • Part 2: Review user account properties
  • Part 3: Modify local user accounts

You start signed in as CyberOpsUser, an administrator. Its password is Cisco123!. You will need it when you sign back in.

Part 1: Create a new local user account

Step 1: Open the User Accounts tool

  1. Open Control Panel from Start. Set View by to Small icons, then choose User Accounts.

Step 2: Create a user account

  1. In User Accounts, choose Manage another account, then Add a new user in PC settings. The Settings app opens on Accounts, Other users.
  2. Choose Add account. When Windows asks how this person will sign in, choose I don't have this person's sign-in information, then Add a user without a Microsoft account.
  3. Create the account with the user name User1. Give it a password you will remember, for example Passw0rd!, and answer the three security questions. Choose Next.

What type of user account did you just create?

A local account (not linked to a Microsoft account) with standard user rights. A standard user cannot change system-wide settings or install software for everyone without an administrator's approval.

  1. Open Start and choose Sign out. On the sign-in screen, choose User1, type its password, and sign in. Windows creates the User1 profile folder the first time the account signs in.
  2. Open File Explorer and go to C:\Users. Select the User1 folder, open its Actions, choose Properties, and look at the Security tab.

Which groups or users have full control of the User1 folder?

SYSTEM, the Administrators group, and the user User1.

  1. Still signed in as User1, try to open the CyberOpsUser folder in C:\Users.

Were you able to open the CyberOpsUser folder? Explain.

No. Windows said you do not have permission to access the folder. Only SYSTEM, Administrators, and CyberOpsUser have access to it, and User1 is a standard user, so it cannot give itself access.

  1. Sign out of User1 and sign back in as CyberOpsUser (password Cisco123!).
  2. In File Explorer, go to C:\Users, select the CyberOpsUser folder, and open the Security tab of its Properties.

Which groups or users have full control of the CyberOpsUser folder?

SYSTEM, the Administrators group, and the user CyberOpsUser.

Part 2: Review user account properties

  1. Open Computer Management (search for it in Start, or open Control Panel, then Windows Tools). Windows Tools was called Administrative Tools in Windows 10.
  2. In the console tree, expand System Tools, then Local Users and Groups, and select Users.
  3. Select User1, open its Actions, choose Properties, and go to the Member Of tab.

Which group is User1 a member of?

Users

  1. Close the dialog. Open the Properties of CyberOpsUser and check its Member Of tab.

Which groups is CyberOpsUser a member of?

Administrators and Users. (On some Windows builds the first account lists only Administrators. Either way, membership in Administrators is what gives it administrator rights.)

Part 3: Modify local user accounts

Step 1: Change the account type

  1. In Control Panel, open User Accounts, choose Manage another account, and select User1.
  2. Choose Change the account type, select Administrator, and choose Change Account Type. User1 now has administrator rights.
  3. In Computer Management, open the Properties of User1 again and check the Member Of tab. (If Computer Management was already open, select Users again to refresh the list.)

Which groups does User1 belong to now?

Administrators and Users.

  1. On the Member Of tab, select Administrators and choose Remove, then OK. User1 is a standard user again.

Step 2: Delete the account

  1. In Computer Management, select User1, open its Actions, and choose Delete. Read the warning, then choose Yes.

What is another way to delete a user account?

Control Panel, User Accounts, Manage another account, select the account, then Delete the account. In Windows 11 you can also use Settings, Accounts, Other users, select the account, then Remove.

Reflection

Why is it important to protect every account with a strong password?

An account with no password or a weak one lets almost anyone sign in and steal data, change settings, or use the computer for attacks. Any account is a way in, not only the administrator account.

Why would you create a user with standard rights instead of administrator rights?

This follows the principle of least privilege. A standard user cannot change system-wide settings, install software for everyone, or read other users' files, so a mistake or a malware infection in that account does much less damage.
