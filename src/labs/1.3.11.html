About this lab

PowerShell is both a command console and a scripting language for automating Windows. In this lab you compare it with the older Command Prompt, find out how PowerShell commands (called cmdlets) are named, use netstat to look at network connections and the processes behind them, and empty the Recycle Bin with one command.

Objectives

  • Part 1: Access the PowerShell console
  • Part 2: Explore Command Prompt and PowerShell commands
  • Part 3: Explore cmdlets
  • Part 4: Explore the netstat command using PowerShell
  • Part 5: Empty the Recycle Bin using PowerShell

Part 1: Access the PowerShell console

  1. Open Start, search for powershell, and open Windows PowerShell.
  2. Open Start again, search for command prompt, and open Command Prompt.

Use the taskbar to switch between the two windows. Each command window's prompt tells you which one you are in: PowerShell prompts start with PS.

Part 2: Explore Command Prompt and PowerShell commands

  1. Run dir in both windows.

What does the dir command show in each window?

Both list the folders and files in the current folder with the date and time each was last changed and the size of each file. Command Prompt marks folders with <DIR> and adds totals at the end. PowerShell adds a Mode column that shows attributes, such as d for a directory and a for archive.

  1. Try other commands you know from Command Prompt in both windows, such as ping www.cisco.com, cd Documents, and ipconfig.

What are the results?

The output is the same or very similar in both windows. PowerShell runs these familiar commands so people can move from Command Prompt easily, either by running the same program (ping, ipconfig) or through an alias (cd).

Part 3: Explore cmdlets

PowerShell commands, called cmdlets, are named as a verb and a noun joined by a hyphen, such as Get-Process. Many familiar command names are aliases for a cmdlet.

  1. In PowerShell, run Get-Alias dir.

What is the PowerShell cmdlet for dir?

Get-ChildItem

  1. To learn more about cmdlets, you could search the web for Microsoft PowerShell cmdlets. (Web search is not part of this simulation.)
  2. Close the Command Prompt window.

Part 4: Explore the netstat command using PowerShell

  1. In PowerShell, run netstat /? to see the options for netstat. (The original lab uses netstat -h. That also prints the help, but only because Windows does not recognize -h.)
  2. Run netstat -r to display the routing table.

What is the IPv4 default gateway?

192.168.1.1. It is the Gateway for the 0.0.0.0 network destination, which is the default route. Your real computer's gateway will usually be different.

  1. Open a second PowerShell window as an administrator: open Start, search for powershell, and choose Run Windows PowerShell as administrator. Choose Yes in User Account Control.
  2. In the administrator window, run netstat -abno. It lists each connection with the process ID (PID) that owns it and the program name. (Try it in the regular window first if you want to see the error it gives without administrator rights.)
  3. Open Task Manager (search for it in Start, or use Taskbar options). On a real PC the shortcut is Ctrl+Shift+Esc. Go to the Details tab.
  4. Pick one PID from the netstat output, such as 756. Sort by the PID column or use Jump to PID to find it, then open the Properties for that process from its Actions.

What information can you get from the Details tab and the Properties window for the PID you chose?

For PID 756: the process is svchost.exe (Host Process for Windows Services), it runs as the NETWORK SERVICE user, it is using about 4,132 K of memory, and its file is in C:\Windows\System32. netstat showed it is the RpcSs service listening on TCP port 135.

Part 5: Empty the Recycle Bin using PowerShell

One PowerShell command can replace several clicks, and the same command can run on many computers at once. That is why administrators use PowerShell to manage large networks.

  1. Open the Recycle Bin (search for it in Start) and check that it has items in it. In this simulation it already does.
  2. In a PowerShell window, run Clear-RecycleBin. When PowerShell asks you to confirm, type Y and press Enter.
  3. Switch back to the Recycle Bin window.

What happened to the files in the Recycle Bin?

They were deleted permanently. The Recycle Bin is now empty.

Reflection

PowerShell was built for task automation and configuration management. Research commands that could simplify your work as a security analyst, and record what you find.

Answers vary. Examples: Get-Process and Get-Service to list what is running, Get-NetTCPConnection to see connections and owning processes, Get-WinEvent to search event logs, Get-FileHash to check whether a file matches a known hash, and Get-LocalUser to review accounts. You can try Get-Process, Get-Service, and Get-Alias in this simulation.

Corrections from the original lab

  • The original netstat -abno table labels three columns "Local Address." They are Local Address, Foreign Address, and State.
  • A route in the original output reads "169.254.0." It should be 169.254.0.0. This simulation uses a simpler routing table.
  • The original uses netstat -h. The documented help option is netstat /?.
  • The Get-Alias output in the original has its columns run together. Here it is shown with spacing and as a table.
