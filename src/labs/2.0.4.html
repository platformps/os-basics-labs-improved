About this lab

A virtual machine (VM) is a computer that runs as software inside a physical computer. The physical computer is called the host and the virtual machine is the guest. In this course, labs run on two virtual machines: the CSE-LABVM and the Security Workstation. In this lab you install VirtualBox, import both virtual machines, start them, and save their state.

Objectives

  • Part 1: Prepare a host computer for virtualization
  • Part 2: Import the virtual machines into the VirtualBox inventory

Why this simulation exists: Installing VirtualBox and using a virtual machine's desktop are very hard to do with a screen reader. This simulation lets you learn every step, and every later lab in this course has a simulated virtual machine, so you do not need to install anything. If you install the real VirtualBox later, the steps match.

What a real installation needs

  • A 64-bit computer with at least 4 GB of RAM to spare for virtual machines and about 50 GB of free disk space. The image files are about 5 GB together and can grow once the machines are in use.
  • Hardware virtualization turned on in the computer's BIOS or UEFI settings. If a 64-bit virtual machine will not start, this setting is the usual cause.
  • A fast internet connection for the downloads.

Part 1: Prepare a host computer for virtualization

Step 1.1: Download and install VirtualBox

VMware Workstation Player and Oracle VirtualBox are two free virtualization programs. This course uses VirtualBox.

  1. Open Microsoft Edge from Start and go to www.virtualbox.org.
  2. Choose Download VirtualBox, then Windows hosts, because the host computer runs Windows.
  3. Open File Explorer, go to Downloads, and open the VirtualBox installer. Accept the default settings on each page and choose Yes when User Account Control asks. Leave Start Oracle VirtualBox after installation checked and choose Finish.

Step 1.2: Download the virtual machine image files

Each virtual machine comes as an OVA file. OVA is a single-file package in the Open Virtualization Format (OVF), an open standard for sharing virtual machines. It holds everything needed to recreate the machine.

  1. In Microsoft Edge, go to labvms.example/osb, the simulated course download page. (In the real course, use the link on the lab page.)
  2. Download CSE-LABVM.ova and Security_Workstation.ova. On a real connection this can take more than an hour.

Part 2: Import the virtual machines into the VirtualBox inventory

Step 2.1: Import the CSE-LABVM

  1. In VirtualBox (open it from Start if it is not open), open the File menu and choose Import Appliance.
  2. For the file, choose Browse, pick CSE-LABVM.ova, and choose Next.
  3. On the Appliance settings page, keep the default machine base folder (it is in your user folder) and set MAC Address Policy to Generate new MAC addresses for all network adapters. Leave everything else as it is and choose Import.
  4. When the import finishes, the CSE-LABVM appears in the VirtualBox inventory, the list of virtual machines.

Step 2.2: Start the CSE-LABVM

  1. Select CSE-LABVM in the inventory and choose Start. A new window opens and the machine boots, then logs in automatically as cisco. If you ever need administrator (sudo) rights in this machine, the user name is cisco and the password is password.

Keyboard focus on a real PC: when you click inside a real virtual machine window, the guest takes over your keyboard and mouse, and your host computer stops seeing your keystrokes. Press the host key to give them back: the right Ctrl key on Windows and Linux, or the left Command key on a Mac. Copy and paste between host and guest also does not work until you turn it on in VirtualBox. If a real virtual machine will not start, try turning off the USB controller in its settings, or install the VirtualBox Extension Pack.

Step 2.3: Get to know the CSE-LABVM

The CSE-LABVM desktop has a launcher with these items: cisco's Home (the cisco user's home folder), DPI Scaling (makes the screen easier to read), Firefox Web Browser, jcryptool (a cryptography tool), Keyboard (keyboard layout), Terminal (the command line), and Wireshark (a packet analyzer).

  1. In the CSE-LABVM window, open Terminal from the launcher and run ip address.

Which IP addresses are assigned to the virtual machine?

The loopback interface lo has 127.0.0.1/8, and the Ethernet interface enp0s3 has 10.0.2.15/24, in the 10.0.2.0/24 network. That network is VirtualBox's built-in NAT network, which shares the host's internet connection.

  1. Open Firefox Web Browser from the launcher.

Can the virtual machine reach your favorite search engine?

Yes. The guest reaches the internet through the host's connection.

Step 2.4: Close the CSE-LABVM

  1. In the virtual machine window, open the File menu and choose Close.

What options are available?

Save the machine state, Send the shutdown signal, and Power off the machine.

  1. Choose Save the machine state and then OK. Next time, the machine resumes exactly where you left it.

Step 2.5: Import and start the Security Workstation

  1. Import Security_Workstation.ova the same way you imported the CSE-LABVM.
  2. Select Security Workstation and choose Start.
  3. If VirtualBox reports that a network interface was not found, choose Change Network Settings. In the Name list, choose the network adapter your computer uses to reach the internet, then choose OK.
  4. At the login screen, sign in as analyst with the password cyberops.

Step 2.6: Get to know the Security Workstation

The Security Workstation is based on Arch Linux, a lightweight Linux distribution, so it can run many services without slowing down your computer. You will use it in many later labs.

Step 2.7: Close the Security Workstation

  1. Open the File menu in its window, choose Close, choose Save the machine state, and then OK.

Reflection

What are the advantages and disadvantages of using a virtual machine?

Advantages: you can try new applications or operating systems without affecting the host, save the machine's state and pick up later, and go back to an earlier state if something breaks. Disadvantages: a virtual machine uses the host's resources, such as disk space, memory, and processing power, so the host needs enough of each.

Corrections from the original lab

  • The original says the Ethernet interface gets an address "in the 10.0.2.15/24 network." The network is 10.0.2.0/24; 10.0.2.15 is the machine's address in it.
  • The original says to press the right Ctrl key to release the keyboard. That is the host key on Windows and Linux; on a Mac it is the left Command key.
  • The original lists a launcher item called "DPI Scanling." It is DPI Scaling.
  • The original calls the second machine both the Security Workstation and, in other labs, the CyberOps Workstation VM. This version uses Security Workstation.
