About this lab

Windows includes tools for watching and managing the computer's resources. In this lab you start and stop a Windows service and watch the effects in three places, find the matching entries in the System log, and set up Performance Monitor to record memory use to a file you can open.

Objectives

  • Part 1: Start and stop the Routing and Remote Access service
  • Part 2: Work in the Computer Management utility
  • Part 3: Configure administrative tools

Graphs as text: Performance Monitor's live graph is shown here as readings (latest, average, minimum, and maximum). The original question asks you to match graph colors; this version asks you to read the counter list instead, which works on a real PC with a screen reader too.

Part 1: Start and stop the Routing and Remote Access service

Step 1.1: Start and stop the Routing and Remote Access service

Routing and Remote Access lets a Windows computer act as a router or accept incoming remote connections. You will start it, watch what changes, and then stop and disable it.

  1. Open Control Panel, set View by to Small icons, and open Network and Sharing Center. Choose Change adapter settings. The Network Connections window opens. Leave it open.
  2. Open Windows Tools (Administrative Tools in Windows 10) from Control Panel, then open Performance Monitor.
  3. In the console tree, select Performance Monitor under Monitoring Tools. Choose Freeze Display to pause the recording, then open Graph actions and choose Clear. Leave the window open.
  4. From Windows Tools, open Services. Select Routing and Remote Access and open its Properties.
  5. Set Startup type to Manual and choose Apply. The Start button becomes available. Do not choose Start yet, and leave the dialog open. (In this simulation the dialog is modal, so first close it with OK, do the next step, then reopen the Properties to start the service.)
  6. Switch to Performance Monitor and choose Unfreeze Display so it records again.
  7. Switch to Services, open the Properties of Routing and Remote Access, and choose Start. A progress message appears while the service starts. Then choose OK.
  8. Switch to Network Connections and choose Refresh (F5 on a real PC).

What changed in Network Connections after you started Routing and Remote Access?

A new item, Incoming Connections, appeared.

  1. In Services, open the Properties again and choose Stop. Then refresh Network Connections.

What changed in Network Connections after you stopped the service?

Incoming Connections disappeared.

  1. Switch to Performance Monitor and choose Freeze Display. Read the counter list under the graph and the readings.

Which counter is being recorded, and what happened to it when you started the service?

% Processor Time for the Processor Information object, instance _Total. It is the only counter Performance Monitor shows by default. Its maximum reading jumped while the service was starting, because starting a service uses the processor.

  1. Open Change graph type and choose Report.

What value does the report show for the counter?

Answers vary. The report shows one number for % Processor Time, for example 2.804, which is the latest reading.

  1. In Services, open the Properties of Routing and Remote Access, set Startup type to Disabled, and choose OK.

What are the Status and Startup Type of Routing and Remote Access now?

Status is blank (the service is not running) and Startup Type is Disabled.

  1. In Performance Monitor, choose Unfreeze Display. Close the windows you opened in Part 1.

Part 2: Work in the Computer Management utility

Step 2.1: Work in the Computer Management utility

Computer Management manages a local or remote computer. Its tools are grouped into System Tools, Storage, and Services and Applications.

  1. Open Computer Management from Windows Tools or Start.
  2. Expand System Tools, then Event Viewer, then Windows Logs, and select System.
  3. Select the newest event and choose Open event properties. Use Next and Previous (or the Down and Up Arrow keys) to move through the log. Find the four events from Service Control Manager about Routing and Remote Access.

What are the descriptions of the four events, in the order they happened?

All four come from Service Control Manager. Oldest first:

  1. Event 7040: The start type of the Routing and Remote Access service was changed from disabled to demand start. (Demand start is the same as Manual.)
  2. Event 7036: The Routing and Remote Access service entered the running state.
  3. Event 7036: The Routing and Remote Access service entered the stopped state.
  4. Event 7040: The start type of the Routing and Remote Access service was changed from demand start to disabled.

The log lists newest first, so you see them in the reverse order.

  1. Close Computer Management.

Part 3: Configure administrative tools

Now you set up Performance Monitor to record available memory every few seconds into a file.

Step 3.1: Create a data collector set

  1. Open Performance Monitor. In the console tree, expand Data Collector Sets and select User Defined. Open Actions for User Defined and choose New, then Data Collector Set.
  2. Name it Memory Logs, choose Create manually (Advanced), and choose Next.
  3. Choose Create data logs, check Performance counter, and choose Next.
  4. Choose Add. In Add Counters, expand Memory, select Available MBytes, choose Add, then OK.
  5. Set Sample interval to 4 seconds and choose Next.
  6. For the root directory, choose Browse, select Local Disk (C:), then PerfLogs, and choose OK. Choose Next.
  7. Leave Save and close selected and choose Finish.

Step 3.2: Change the log format

  1. Under User Defined, select Memory Logs. Select DataCollector01, open its Actions, and choose Properties.
  2. On the Performance Counters tab, change Log format to Comma Separated. Then go to the File tab.

What is the full path of the example file name?

It is C:\PerfLogs\ followed by a folder named with the computer name and a date and number, then DataCollector01.csv. In this simulation: C:\PerfLogs\DESKTOP-OSB01_ then today's date and -000001, then \DataCollector01.csv.

  1. Choose OK.

Step 3.3: Collect data

  1. With Memory Logs selected, choose Start the Data Collector Set. Its status changes to Running. (The real tool shows a green arrow on the icon.)
  2. To make the computer use some memory, open Microsoft Edge from Start and then close it.
  3. Switch to Performance Monitor and choose Stop the Data Collector Set.

What changed for Memory Logs when you stopped it?

Its status changed from Running back to Stopped. In the real tool, the green arrow on the Memory Logs icon goes away.

  1. Open File Explorer and go to C:\PerfLogs. Open the folder that starts with the computer name, then open DataCollector01.csv. It opens in Notepad. Use the table view below the text to read it as a table.

What does the column farthest to the right show?

Available memory in megabytes (the \Memory\Available MBytes counter), one reading every 4 seconds. The first column is the time of each reading.

Step 3.4: Clean up

  1. Close Notepad and File Explorer.
  2. In Performance Monitor, select Memory Logs under User Defined, open its Actions, and choose Delete. Confirm with Yes.
  3. In File Explorer, go to C:\PerfLogs, select the folder that held the log, and choose Delete from its Actions. Confirm with Yes.

Corrections from the original lab

  • The original says the Event Properties window "opens for the first event" without a step that opens it. This version tells you to open it.
  • The original's answer for the four events is only "Answers will vary." The four events are always the same, so this version gives them.
  • The original asks which counter is recorded most by matching graph colors. This version reads the counter list, which does not depend on color.
  • The original says to expand "the three categories" with one arrow. Each category has its own expand control.
  • The original uses both "Data Collector01" and "DataCollector01." The name is DataCollector01.
  • The original uses Start, Computer to open drive C:. Current Windows uses File Explorer, This PC.
  • The original note about "Windows cannot open the file" is not needed here; the CSV file opens in Notepad.
